# 💻 Coding Test Study

Java와 Python을 활용한 코딩테스트 학습 저장소입니다.

자료구조와 알고리즘을 학습하고, 프로그래머스 문제 풀이를 기록합니다.

## 🛠 Study Environment

- **Languages:** Java, Python
- **Platform:** Programmers
- **IDE:** VS Code
- **Auto Commit:** BaekjoonHub

## 📚 Algorithm Study

자료구조 및 알고리즘의 개념과 예제 코드를 유형별로 정리합니다.

`basics/`는 『이것이 취업을 위한 코딩테스트다 with 파이썬』 학습 내용을 기반으로 하며, Java와 Python 구현 코드를 함께 관리합니다.

| 유형           | 주요 내용                                | 바로가기                                       |
| -------------- | ---------------------------------------- | ---------------------------------------------- |
| Implementation | 구현, 시뮬레이션                         | [정리 보기](./basics/implementation/README.md) |
| Sorting        | 선택 정렬, 삽입 정렬, 퀵 정렬, 계수 정렬 | [정리 보기](./basics/Sorting/README.md)        |
| DFS / BFS      | 깊이 우선 탐색, 너비 우선 탐색           | [정리 보기](./basics/DFS-BFS/README.md)        |
| Binary Search  | 순차 탐색, 이진 탐색                     | [정리 보기](./basics/binary-search/README.md)  |
